# Q14 — Proof of booking is a report, a calendar event and a confirmation email

- **Status:** Accepted
- **Decided:** 2026-09-20/22 (rounds 1–3)
- **Followed interviewer recommendation:** yes

## Question

What counts as proof of a booking?

## Decision

All three: a report to the user, an event in the user's calendar, and a confirmation email to the business.

## Alternatives considered

- Report only

## Why

Written confirmation to both sides catches mishearing that a transcript alone won't.

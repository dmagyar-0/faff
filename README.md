# Faff

A UK consumer web app that handles life admin by phone and email, for people who'd rather not make the call. It starts with booking, rescheduling and cancelling appointments.

The chat agent drafts a **Task Brief**, the user approves it, and an agent that always says it's an AI carries it out. It never pretends to be the user.
